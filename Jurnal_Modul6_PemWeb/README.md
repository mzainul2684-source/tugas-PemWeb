## 1. Pengertian JavaScript dan Kegunaannya

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web menjadi dinamis dan interaktif. JavaScript dapat digunakan untuk menerima input pengguna, memvalidasi formulir, mengubah isi halaman, serta memberikan respons ketika pengguna mengeklik tombol.


## 2. Pengertian jQuery dan Kegunaannya

jQuery adalah pustaka JavaScript yang mempermudah penulisan kode untuk berinteraksi dengan elemen HTML. jQuery dapat digunakan untuk mengubah tampilan elemen, menangani klik tombol, membuat animasi, serta mengambil atau mengirim data menggunakan AJAX.


## 3. Perbedaan JavaScript dan jQuery

| Aspek | JavaScript | jQuery |
| --- | --- | --- |
| Pengertian | Bahasa pemrograman. | Pustaka yang dibuat menggunakan JavaScript. |
| Ketergantungan | Dapat digunakan tanpa jQuery. | Memerlukan JavaScript dan pemuatan pustaka jQuery. |
| Penulisan kode | Menggunakan fitur bawaan JavaScript. | Menyediakan fungsi yang menyederhanakan beberapa pekerjaan. |
| Manipulasi HTML | Dapat menggunakan `document.getElementById()`. | Dapat menggunakan selector seperti `$("#nama")`. |
| Menyembunyikan elemen | Mengatur `style.display = "none"`. | Menggunakan fungsi `.hide()`. |

JavaScript dan jQuery saling berkaitan karena jQuery dibangun menggunakan JavaScript.
